# BUCCS Notebooks

Machine-learning fundamentals on how to handle urban temperature
measurement network data, from data preprocessing, to adding predictors,
splitting the data and training models.
Developed during the Bochum Urban Climate Summer School (2026).


## Installation

conda activate <your-env>          
pip install -e .

<your-env> should contain the following basic packages: 
pandas
matplotlib
contextily
numpy
pyproj
cmcrameri
sklearn
rasterio
xgboost
